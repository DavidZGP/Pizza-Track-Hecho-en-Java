# Objetivo del proyecto

El objetivo principal de esta actividad fue comprender el funcionamiento de las pilas y las listas ligadas mediante el desarrollo de un sistema práctico en consola.

Para esto se implementaron dos pilas manuales:

- Pila principal → almacena pedidos activos
- Pila secundaria → almacena pedidos deshechos temporalmente

---

# Tecnologías utilizadas

- Java
- Programación Orientada a Objetos (POO)
- Listas ligadas
- Pilas manuales
- Consola

# Instrucciones de ejecución

1. Descargar o clonar el repositorio.

2. Abrir el proyecto en un IDE compatible con Java como:
   - NetBeans
   - IntelliJ IDEA
   - Visual Studio Code

3. Verificar que todos los archivos `.java` estén en el mismo proyecto:
   - Pizza.java
   - NodoPizza.java
   - PilaPizza.java
   - GestionPedidos.java

4. Compilar el proyecto.

5. Ejecutar el archivo `GestionPedidos.java`, ya que contiene el método `main`.

6. Utilizar el menú en consola para interactuar con el sistema:
   - Registrar pizzas
   - Deshacer pedidos
   - Rehacer pedidos
   - Mostrar pedido actual
